# mesh-viewer-three-js
Using JavaScript and the three.js library to create a simple mesh viewer with options to change the mesh, enable wireframe, change the mesh color, and randomize the 3 values.

This repo was created as part of an exercise in one of my classes to choose a JavaScript library (three.js in this case) and program a small project out of it. I spent more time than I could've, but I wanted to experiment with coding a bigger project than I intended!
